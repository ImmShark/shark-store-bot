Đặt 3 file ảnh sau đây vào thư mục này (tên file phải đúng y hệt):

  logo.png    → logo shop (hình vuông, hiển thị góc phải mọi embed)
  banner.png  → ảnh banner rộng (hiển thị dưới bảng giá, verify, ticket...)
  legit.gif   → GIF động dùng cho embed Legit (phải là file GIF thật)

Khi có đủ file, bot sẽ TỰ ĐỘNG ưu tiên dùng ảnh trong thư mục này và tự upload
kèm mỗi tin nhắn → link ảnh sẽ KHÔNG BAO GIỜ hết hạn như link media.discordapp.net.

Nếu chưa có file, bot dùng lại link trong config.js (mục IMAGES).

Lưu ý: cần đủ cả 3 file, thiếu file nào thì ảnh đó sẽ dùng fallback URL.
